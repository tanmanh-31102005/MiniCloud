Chuyên đề 03 • Observability & Monitoring

Giám Sát Tài Nguyên Hệ Thống Với Prometheus & Trực Quan Hóa Cùng Grafana

Tác giả: Nhóm Đồ Án MyMiniCloud | Cập nhật: 2026

"Bạn không thể tối ưu hóa hoặc bảo vệ những gì mà bạn không thể đo lường và quan sát."

1. Mô hình giám sát kéo (Pull-based) của Prometheus

Trong thế giới Cloud Computing, Prometheus là tiêu chuẩn thực tế (de-facto standard) cho việc thu thập số liệu dạng chuỗi thời gian (Time-series Metrics). Khác với mô hình Push (nơi máy chủ giám sát thụ động chờ các node gửi tin báo), Prometheus chủ động gửi HTTP GET request định kỳ (chu kỳ scrape interval, thường là 15 giây) đến các endpoint /metrics của từng dịch vụ.

2. Thu thập chỉ số phần cứng qua Node Exporter

Để thu thập các chỉ số tài nguyên cấp hệ thống (CPU, Bộ nhớ RAM, Lưu lượng Network I/O, Ổ đĩa), chúng ta triển khai container monitoring-node-exporter-server lắng nghe tại cổng 9100. Container này đọc trực tiếp thông tin từ hệ thống tập tin /proc và /sys của Linux kernel và định dạng chúng theo chuẩn Prometheus exposition format.

3. Tự động hóa nạp cấu hình Dashboard trên Grafana (Provisioning)

Thông thường khi mới khởi chạy Grafana, kỹ sư phải đăng nhập, tạo Data Source kết nối Prometheus và dựng từng biểu đồ thủ công. Trong dự án MyMiniCloud, chúng ta áp dụng kỹ thuật Infrastructure as Code (IaC) cho Observability bằng cách sử dụng cơ chế Provisioning:

  • datasources/prometheus.yml: Tự động khai báo và kết nối nguồn dữ liệu Prometheus ngay khi container khởi động.
  • dashboards/system-health.json: Tự động khởi tạo sẵn Dashboard System Health hiển thị 3 biểu đồ trọng yếu: CPU Usage (%), Memory Usage (MB/GB) và Network Traffic.
