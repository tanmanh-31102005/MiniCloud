9 Dịch Vụ Cốt Lõi Trong Hạ Tầng MyMiniCloud

1. Web Frontend Server

Cung cấp website giao diện tĩnh và Blog kỹ thuật. Hỗ trợ 2 máy chủ Web chạy cơ chế cân bằng tải Round Robin.

Đọc Blog
2. Application Backend API

Python Flask Microservice cung cấp REST API, trích xuất dữ liệu JSON sinh viên, kết nối CSDL và xác thực token.

Xem /student JSON
3. Relational Database

MariaDB lưu trữ CSDL quan hệ studentdb, duy trì dữ liệu qua Docker Volume bền vững với script khởi tạo tự động.

Truy Vấn CSDL
4. Authentication & IAM

Keycloak OIDC Provider quản lý định danh người dùng tập trung, tạo Realm MyMiniCloud và cấp phát JWT token.

Keycloak Console
5. Object Storage (S3)

MinIO lưu trữ đối tượng phi cấu trúc. Tự động tạo bucket profile-pics (ảnh avatar) và documents (tài liệu PDF).

MinIO Console (:9001)
6. Internal DNS Server

BIND9 quản lý Zone phân giải tên miền nội bộ cloud.local cho phép các container ánh xạ tên miền dịch vụ linh hoạt.

Port 1053/udp
7. Monitoring Server

Prometheus định kỳ scrape metrics tài nguyên từ Node Exporter, metrics HTTP từ Flask Backend và Web Server.

Prometheus Targets
8. Visualization Dashboard

Grafana hiển thị biểu đồ trực quan CPU, RAM, Network Traffic với Dashboard System Health được cấu hình tự động.

Grafana (:3000)
9. API Gateway & Proxy

Nginx Gateway là điểm tiếp nhận duy nhất trên cổng 80, định tuyến path-based và cân bằng tải Round Robin giữa 2 Web Node.

Port 80 (Active)
